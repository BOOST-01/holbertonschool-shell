# Shell, init files, variables and expansions

## 0. \<o>
The script creates an alias named ls that runs rm -f *.

## 1. Hello you

The script displays hello followed by the current Linux username using whoami.

## 2. Path

The script adds /action to the end of the PATH environment variable.

## 3. Paths

The script counts the directories listed in the PATH environment variable.

## 4. Global variables

The script displays all environment variables using printenv.

## 5. Local variables

The script displays shell variables, environment variables, and functions using set.

## 6. Create local variable

The script creates a local variable named BEST with the value School.

## 7. Create global variable

The script exports a global variable named BEST with the value School.

## 8. True knowledge

The script adds 128 to the TRUEKNOWLEDGE environment variable.
