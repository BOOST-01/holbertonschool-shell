# Shell, I/O Redirections and filters

This project contains Bash scripts for practicing shell input, output, redirections, and filters.

## 0. Hello World

The script prints Hello, World followed by a new line.

## 1. Confused smiley

The script displays the confused smiley "(Ôo)'.

## 2. Let's display a file

The script displays the contents of /etc/passwd.

## 3. What about 2?

The script displays the contents of /etc/passwd and /etc/hosts.

## 4. Last lines of a file

The script displays the last 10 lines of /etc/passwd.

## 5. First lines of a file

The script displays the first 10 lines of /etc/passwd.

## 6. Line #2

The script displays the third line of the file iacta.

## 7. File name

The script creates a file with a special name containing the text Best School.
