# Shell, I/O Redirections and filters

This project contains Bash scripts for practicing shell input, output, redirections, and filters.

## 0. Hello World

The script prints Hello, World followed by a new line.

## 1. Confused smiley

The script displays the confused smiley "(Ôo)'.

## 2. Let's display a file

The script displays the contents of /etc/passwd.

## 3. What about 2?

The script displays the contents of /etc/passwd and /etc/hosts.

## 4. Last lines of a file

The script displays the last 10 lines of /etc/passwd.

## 5. First lines of a file

The script displays the first 10 lines of /etc/passwd.

## 6. Line #2

The script displays the third line of the file iacta.

## 7. File name

The script creates a file with a special name containing the text Best School.

## 8. Save current state of directory

The script saves the output of ls -la into ls_cwd_content, overwriting it if it already exists.

## 9. Duplicate last line

The script appends a copy of the last line of iacta to the file.

## 10. No more javascript

The script deletes regular files with the .js extension in the current directory and its subdirectories.

## 11. Directories

The script counts all directories and subdirectories, including hidden directories, excluding the current and parent directories.

## 12. What's new

The script displays the 10 newest files in the current directory, sorted from newest to oldest.

## 13. Being unique is better than being perfect

The script sorts input words and displays only words that appear exactly once.

## 14. It must be in that file

The script displays lines containing the word "root" from /etc/passwd.
